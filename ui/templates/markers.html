Markers

Markers turn activity numbers into words. Most metrics hold named sets of ranges; a template uses one as {metric.name}, e.g. {distance.category}. Counters are different: enter a JSON object mapping each counter name to its base value. The counter increments before use, so a base of 99 produces 100 the first time. Existing values in counters.json are kept. Edit each metric as JSON; an empty box removes the metric.
